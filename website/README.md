# Documentation site

Docusaurus site for playwright-logger-pro, published to <https://ijad-org.github.io/playwright-logger-pro/> by `.github/workflows/docs.yml`. It is a standalone npm project: it is not part of the library package and not in the pnpm workspace.

```sh
npm ci
npm run build        # sync-changelog + check-config + docusaurus build (also generates docs/api with TypeDoc)
npm run serve        # http://localhost:3000/playwright-logger-pro/
npm start            # dev server (the search dialog lists topics but returns no results; search needs a build)
npm run typecheck
npm test             # Playwright smoke tests against the built site (npx playwright install chromium first)
```

Prerequisites: the library is built (`npm run build` in the repository root) and its dependencies are installed there (TypeDoc reads `../src` and needs `@playwright/test` types; `check-config` reads `../dist`).

## Layout

- `docs/` guides and reference (`docs/api/` is generated by TypeDoc and git-ignored)
- `src/pages/` home and 404 (`changelog.md` is generated from the root `CHANGELOG.md`, git-ignored)
- `src/components/TerminalOutput` renders ANSI samples from `src/data/samples/*.ansi` (real output, regenerate with `node scripts/gen-doc-samples.mjs` from the repository root; needs Chromium)
- `src/theme/SearchBar` the Ctrl/Cmd+K dialog (see below), `src/theme/MDXComponents.tsx` global MDX components
- `plugins/` the topics list for the search dialog, TypeDoc module names
- `scripts/` changelog sync, config-docs check, sample generator
- `static/img` logo, favicons, social card

## Search

Offline: `@easyops-cn/docusaurus-search-local` builds a lunr index at build time (`build/search-index-<hash>.json`). Our `SearchBar` replaces the plugin's UI with a dialog (Ctrl/Cmd+K, `/`) and reuses the plugin's search worker through `src/theme/SearchBar/searchEngine.ts`. If a plugin upgrade moves those files, that is the only module to adapt.

## Preview phase

Until 0.2.0 is published: the announcement bar in `docusaurus.config.ts` and, optionally, the repository variable `DOCS_NOINDEX=1`. Remove both in the release PR, and snapshot the docs version (`npx docusaurus docs:version 0.2`).
